EquaPix: GPU-Based Image Reconstruction Using Sparse Linear Systems performs grayscale image reconstruction/inpainting on batches of hundreds of small images or tens of large images. It creates deterministic random or rectangular masks and expresses missing pixels as a sparse system A*x=b of local four-neighbor equations with fixed observed pixels. Custom CUDA kernels solve the system using double-buffered Jacobi iteration, with one GPU thread per pixel/equation and no dense NxN matrix. The pipeline outputs original, masked and reconstructed PNG images, representative Matrix Portraits, RMSE/PSNR metrics, and execution logs. A sequential CPU reference validates GPU reconstruction and benchmarks a configurable subset. The included experiment script generates 200 images and runs 5%, 10%, 20% and 30% masking tests.
